# 중학 영단어장

영어가 아직 많이 어려운 중학생을 위한 단어 복습 웹앱입니다. 링크만 있으면 휴대폰이나 아이패드에서 바로 쓸 수 있고, 홈 화면에 추가하면 앱처럼 열리며 인터넷 없이도 작동합니다.

## 파일 구성

| 파일 | 내용 |
|---|---|
| `index.html` | 앱 화면과 기능 전체 |
| `words.json` | **기본 데이터**: 단어 652개, 헷갈리는 짝, 상황 대화, 수행평가 질문, 교과서 단원 목록 |
| `sw.js` | 오프라인 작동과 "새 버전이 있어요" 알림 |
| `manifest.webmanifest`, `icons/` | 홈 화면에 추가할 때 쓰는 앱 이름과 아이콘 |
| `tools/check_words.py` | `words.json` 점검기 |

학생 기기(브라우저)에는 **학습 기록, 설정, 학생이 직접 추가한 단어, 학생이 기본 단어를 고친 부분**만 저장됩니다. 기본 단어는 항상 `words.json`에서 읽어 옵니다.

## 단어 데이터 고치기

1. `words.json`을 메모장이나 VS Code로 엽니다. 단어 하나가 한 줄입니다.

   ```json
   {"id": "e002", "w": "grade", "m": "학년; 성적", "pos": "n", "gr": 1, "c": "school", "ipa": "ɡreɪd", "kp": "그레이드", "exs": [{"ex": "I am in the seventh [grade].", "ko": "나는 7학년(중1)이야."}], "n": 2},
   ```

   | 항목 | 뜻 | 꼭 필요? |
   |---|---|---|
   | `id` | 단어 고유 번호. 학습 기록이 이 번호로 저장되므로 **한번 정하면 바꾸지 마세요** | ✔ |
   | `w` | 영어 | ✔ |
   | `m` | 뜻. 여러 개면 `;`로 구분 | ✔ |
   | `gr` | 학년 1·2·3 | ✔ |
   | `n` | 단어장 순서 번호 | 권장 |
   | `pos` | 품사 `n v adj adv prep conj pron`, 두 개면 `n·v` | |
   | `c` | 분류 `school daily people feel action describe time nature society func` | |
   | `ipa`, `kp` | 발음기호(슬래시 없이), 한글 발음 | |
   | `exs` | 예문 목록, **최대 3개**. `[{"ex": "예문", "ko": "해석"}, ...]` 외울 단어를 `[ ]`로 감싸요. 첫 번째가 대표 예문이고, 나머지는 "예문 더 보기"를 누르면 보여요. 문장 완성 문제는 이 중에서 무작위로 나와요 | 권장 |
   | `col`, `cm` | 덩어리 표현과 해석 | |
   | `forms` | 불규칙 동사 변화 `went - gone` | |
   | `note` | 주의점 한 줄 | |
   | `g` | 헷갈리는 짝 번호 (`groups`에 있는 것) | |
   | `lss` | 교과서 단원 `["L1", "L3"]` | |

   - **단어 추가**: 새 줄을 만들고 아직 쓰지 않은 `id`를 붙입니다(예: `e700`).
   - **단어 빼기**: 그 줄을 지웁니다. 학생의 그 단어 기록은 남지만 화면에는 나오지 않습니다.
   - **내용 고치기**: 뜻이나 예문을 바꾸면 모든 학생에게 반영됩니다. 학생이 앱에서 직접 고친 항목만은 학생 것이 우선입니다.

2. 저장한 뒤 점검기를 실행합니다. `오류 0개`가 나와야 합니다.

   ```bash
   py tools/check_words.py
   ```

3. 변경 사항을 저장(commit)하고 GitHub에 올립니다(push). 1~2분 뒤 사이트에 반영됩니다.

학생이 앱을 열면 위쪽에 **"새 버전이 있어요 · 새로고침"** 알림이 뜹니다. 누르지 않아도 다음에 앱을 열 때 새 버전이 적용됩니다. 버전 번호를 따로 올릴 필요는 없습니다. `version` 항목은 백업 파일에 기록용으로만 남습니다.

## 컴퓨터에서 미리 보기

`index.html`을 더블클릭해서 열면 단어 파일을 불러오지 못합니다. 이 폴더에서 아래 명령을 실행한 뒤 브라우저에서 `http://localhost:8765`를 엽니다.

```bash
py -m http.server 8765
```

## 학생에게 안내할 점

- 공부 기록은 **그 기기의 브라우저에만** 저장됩니다. 기기를 바꾸거나 브라우저 데이터를 지우기 전에는 **단어 관리 → 백업**으로 파일을 저장하고, 새 기기에서 불러오면 됩니다.
- 아이폰·아이패드는 Safari에서 **공유 → 홈 화면에 추가**로 설치해서 쓰세요. 설치하지 않고 Safari로만 열면, 7일 동안 열지 않았을 때 기록이 지워질 수 있습니다.
